Hutred

Установка на телефон

Android — один файл. iPhone — через компьютер с Windows и бесплатный Apple ID.

Android iPhone Ошибка −80045 Каждые 7 дней

Android

  1. Открой на телефоне страницу загрузки и нажми Скачать .apk.
  2. Открой скачанный файл. Если телефон спросит — разреши установку из этого источника (браузера или «Файлов») и вернись назад.
  3. Нажми Установить. Готово: дальше Hutred сам предлагает обновления.

iPhone

Hutred нет в App Store, поэтому ставим через SideStore — он подписывает приложения твоим Apple ID. Один раз нужен компьютер с Windows и кабель.

1. Подготовка компьютера

  1. Скачай и установи iloader — программу, которая ставит SideStore по кабелю (github.com/nab138/iloader → Releases).
  2. Если компьютер не видит айфон — поставь из Microsoft Store приложение Apple Devices (или iTunes).
  3. Подключи айфон кабелем, разблокируй и нажми Доверять этому компьютеру.

2. Установка SideStore

  1. В iloader в разделе Settings выбери сервер Anisette: нажми Use custom Anisette server и впиши https://new.ani.sidestore.io. С этим сервером не бывает ошибки −80045.
  2. Слева Add Account + — войди своим Apple ID и введи код, который придёт на айфон.
  3. Убедись, что сверху в iDevice выбран твой айфон, и нажми SideStore (Stable). Дождись окончания.
  4. На айфоне: Настройки → Основные → VPN и управление устройством → свой Apple ID → Доверять.
  5. Если айфон пишет про Режим разработчика: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить → перезагрузить.

3. Hutred через SideStore

  1. Открой SideStore и войди тем же Apple ID (Settings → Sign In).
  2. Вкладка Sources → + → вставь ссылку:
  3. Вкладка Browse → Hutred → Get. Через минуту он появится на экране «Домой».
  4. Новые версии будут появляться в My Apps кнопкой Update.

Ошибка −80045 при входе в Apple ID

«Failed To Sign In — This action cannot be completed at this time (−80045)». С осени 2026 Apple не пускает вход через старые серверы Anisette. Лечится сменой сервера и сбросом.

Если ошибка в iloader (на компьютере)

  1. Settings → Use custom Anisette server → https://new.ani.sidestore.io.
  2. Нажми Reset Anisette State — это безопасно, сбрасывается только старая регистрация.
  3. Снова Sign in и код подтверждения. Delete Stored Pairing не нажимай — это про кабель, а не про вход.

Если ошибка в SideStore (на айфоне)

  1. Settings → User Customizations → выключи On-Device Anisette (если попросит перезапуск — согласись).
  2. Anisette Servers → выбери SideStore (New) и выключи Enable Auto Rotation.
  3. User Customizations → Anisette Client Configuration → Remote Server Sync → Fetch, потом Save as Overrides. Это главный шаг.
  4. В User Customizations нажми Reset adi.pb.
  5. Полностью закрой SideStore, открой и войди в Apple ID заново.

Не помогло — подожди час: после нескольких неудачных попыток Apple ненадолго блокирует вход.

Каждые 7 дней

Бесплатная подпись Apple живёт 7 дней. Чтобы Hutred не перестал открываться, раз в неделю открой SideStore → My Apps → Refresh All. Если SideStore просит включить свой VPN — поставь из App Store LocalDevVPN и включи его на время обновления.

Если всё же истекло — подключи айфон к компьютеру и в iloader снова нажми SideStore (Stable): Hutred и медиатека останутся.
